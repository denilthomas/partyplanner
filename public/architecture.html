PartyPlanner Architecture

MCP-Powered Agent Pipeline — From Inspiration to Shopping Cart

User Interaction
Claude Orchestrator

Party Bucket (Output)
Phase 1 — Intent
User Input Frontend
User describes their party vision in natural language.
"I want a bohemian garden tea party for 20 guests with a $500 budget"
prompt + context
Phase 2 — Orchestration
Claude Orchestrator Agent
Central brain that coordinates the full pipeline. Interprets user intent, generates search queries, manages the refinement loop, and assembles the final party bucket. Calls MCP tools as needed.
claude-3.5-sonnet / opus · vision-capable
search_pinterest({ query, filters })
Phase 3 — Inspiration Discovery
↻ Refinement Loop
User can refine until satisfied →
Pinterest Scraper MCP Tool
Scrapes Pinterest search results for the given query. Returns an array of high-res image URLs, titles, descriptions, and board metadata. Supports pagination and filter refinement.
search_pinterest(query, count, filters)
image grid → user
User Selection Interactive
User browses inspiration grid. Can:
✓ Select an image to lock in    ↻ Request refinements ("more rustic", "less pink")
Refinements re-trigger the Pinterest scraper with adjusted queries.
selected image URL → Claude vision
Phase 4 — Item Extraction
Vision Extraction Agent Claude Vision
Claude analyzes the selected inspiration image using its native multimodal capabilities. Extracts every identifiable item into a structured list with categories, descriptions, and search-friendly product names.
No MCP needed · native Claude vision
structured item list → search queries
Phase 5 — Product Search
E-Commerce Scraper MCP Tool
Takes each extracted item and searches real retailer websites. Returns actual product listings with verified prices, ratings, availability, and direct purchase URLs.
search_products(query, retailer, max_results)
Amazon
Product Advertising API
or search page scraping
Walmart
Open API
or Affiliate endpoint
Target
Redsky API
or search scraping
real product listings → party bucket
Phase 6 — Output
🎉 Party Bucket Frontend UI
Final curated shopping list displayed to user. Each item shows real product image, name, price, retailer, rating, and a direct "Buy" link. Includes category grouping, budget tracking, and quantity controls.
